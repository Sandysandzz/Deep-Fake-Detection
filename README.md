# Deep-Fake-Detection
DeepGuard AI is an end-to-end deep learning system that detects manipulated (deepfake) facial images and videos. It was built as a BCA Final Year Major Project. It uses transfer learning with EfficientNet-B4, trained on the FaceForensics++ and Celeb-DF datasets, and reaches roughly 93.5% accuracy on the Celeb-DF v2 test set.
